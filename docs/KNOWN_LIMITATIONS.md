# 已知限制

- 当前主机未安装 Docker 与本地 PostgreSQL，因此无法在此机器执行容器启动、真实迁移和数据库持久化冒烟；Compose、迁移、Schema、种子和脚本已静态/单元验证，应在部署机执行 `docker compose up -d --build` 后复验健康状态。
- 默认支付是沙箱，不会产生真实扣款。生产支付需按 `PaymentProvider` 接入持牌服务并完成回调验签。
- 腾讯云直播适配器在缺少完整凭证时强制关闭；本地默认使用 MediaMTX，没摄像头时使用演示视频回退。
- 本地文件存储适合单机；多实例生产应实现并启用 MinIO/S3 持久化提供者及病毒扫描。
- 邮件、短信、推送和实名认证属于需要外部服务资质的能力，当前只保留业务入口与状态，不会伪造外部送达。
- 管理端 Element Plus 当前整包加载，构建产物约 1.1 MB（压缩约 361 KB）；可按需自动导入进一步拆包。
- 浏览器 E2E 使用确定性 API 模拟并与 API 集成测试组合验证；上线前仍需在目标环境补一轮连接真实 PostgreSQL、Redis、MediaMTX 的验收。
