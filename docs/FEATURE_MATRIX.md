# 功能覆盖矩阵

| 产品域 | 用户端 | 主播端 | 审核/管理端 | API/持久化 | 自动化验证 |
|---|---|---|---|---|---|
| 账号与权限 | 登录、刷新、退出、个人资料、设备 | 主播中心、加入申请 | 角色菜单、用户状态、审计 | JWT 轮换、Argon2id、RBAC、Prisma | 单测 + E2E |
| 圈子与内容 | 圈子发现、邀请、动态、收藏、评论 | 发布动态/资料、送审 | 单条/批量审核、驳回原因、下线 | 标签、分页、状态机 | API E2E + 组件测试 |
| 钱包与会员 | 余额、流水、充值商品、会员、订单 | 付费直播定价 | 金币人工调整、交易看板、退款 | 整数账本、幂等订单/回调、退款状态机 | 并发单测 + API/浏览器 E2E |
| 直播互动 | 付费确认、直播观看、预约、聊天 | 创建/开播/断线恢复/结束、第二视角 | 直播列表与运营视图 | MediaMTX、本地演示视频、Socket.IO | 状态机 + API/浏览器 E2E |
| 平台运营 | 公告入口 | 数据概览 | 仪表盘、风险审计、CSV、系统配置 | 遮罩密钥、审计记录 | 管理 API + 浏览器 E2E |
| 文件与外部服务 | 安全上传 | 图片/视频/资料引用 | 存储配置 | 魔数校验、限额、归属校验、腾讯/支付适配器 | 安全 E2E + 适配器单测 |
| 部署运维 | 响应式 Web | 同一套 Web | `/admin/` 独立后台 | PostgreSQL、Redis、MediaMTX、Nginx | Windows 清单与脚本检查 |

## 与调研页面及教程的关系

实现以真实移动页面的信息架构和交互为主：登录、主播列表、圈子、采集/发布、个人设置和主播工作台均有对应流程。教程中强调的主播发文、第二视角邀请、演示视频回退、审核状态和付费能力也已落到数据模型与状态机。未复制原站源码、商标图片、用户数据或私有接口；视觉与文案为独立实现。
